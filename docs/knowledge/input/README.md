# Input

Drop the client's material here before running `grill-me`: the brief, spec, wireframes, exported
emails, meeting notes, a spreadsheet of fields — whatever exists. Any format, any number of files.

Nothing in here is authoritative. It is the raw material `grill-me` reads before interrogating you,
so it can ask about what the material *doesn't* say instead of asking you to retype what it does.

This directory is committed. Do not put credentials or personal data in it.
